# Information
This .ipynb-file should be executed sequentially in Jupyter Notebook. 

You need to have a folder structure as described in the master thesis (Section 4.3.1 Dataset Preparation) and visualized as:


	RawData
	
		dicom1
		
			firstLevelInWsi.dcm
			
			...
			
			lastLevelInWsi.dcm
			
			annotations.geojson
			
		...
	
		dicomN
		
			firstLevelInWsi.dcm
			
			...
			
			lastLevelInWsi.dcm
			
			annotations.geojson

You also need whole-slide images and geojson-annotations. Some WSI can be found at [Zenodo](https://zenodo.org/records/17486627).
